# Blitz: Dimensions of Paradox — Card Studio

Editor web para diseñar y prototipar cartas de Blitz: Dimensions of Paradox.

Incluye habilidades, armas con mapas pintables y paletas, poderes elementales, objetos, enemigos niveles 1–4, cartas IA, personajes y mapas. Los proyectos se pueden guardar localmente y exportar/importar como JSON.
